# نظام العمريين — ملفات التثبيت

هالمستودع فيه **ملفات تثبيت وتحديث** برنامج «نظام العمريين» تبع العمريين للخدمات المطبعية. **ما فيه أي كود.**

- **للتثبيت:** نزّل `AmreenSystem-Setup-<النسخة>.exe` من [Releases](../../releases/latest).
- **التحديث:** البرنامج المثبّت بيحدّث حاله من هون تلقائيًا.

ويندوز ممكن يطلّع «Windows protected your PC»، لأن الملف مش موقّع رقميًا. اكبس **More info** وبعدين **Run anyway**.
